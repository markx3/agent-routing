# Previous comments
Gate: on when the PR already has review comments. Adapted from Every's `ce-code-review`, previous-comments reviewer.

For each existing comment, report whether the current diff addresses it, addresses it partially, or ignores it, and whether the reply in the thread, if any, matches what the code does. Report comments whose thread was resolved without a change that answers them.

Severity: P1 a blocking comment ignored; P2 a comment addressed partially; P3 a resolved thread with no matching change.
