# Spec
Gate: always on.

Does the diff implement what the spec asked for, no more and no less? Report:
- Requirements the spec asks for that are missing or partial.
- Behavior in the diff the spec did not ask for.
- Requirements that look implemented but whose implementation does not match the spec's wording.
Quote the spec line for each finding. When no spec is available, report that and stop.

Severity: P0 a required behavior is absent or inverted; P1 a requirement is partial; P2 unrequested behavior that changes a user-visible path; P3 unrequested behavior with no user-visible effect.
