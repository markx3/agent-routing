# Handoff: <role> <n> for <issue>

## Goal
One sentence, plus the issue number or spec path.

## Current state
Branch, worktree path, PR URL if one exists, last commit SHA.

## Done
Each item with the evidence that proves it: the test command and its result, the typecheck result, the diff range. Reference commits, diffs, plans, and PR comments by SHA, path, or URL instead of restating them.

## Not done
What the goal still needs, in the order you would do it.

## Open findings
Review findings and CI failures still unaddressed, each as `file:line`, the finding, its severity.

## Decisions
Each decision you made that the spec did not settle, and why.

## Unsure
What you could not confirm, what you guessed at, where you suspect you are wrong.

## Gotchas
Commands that failed and why, environment quirks, anything that cost you time.

## Next step
The single action the next agent should take first.

## <role> notes
Free-form, role-specific. Builders: test seams used, files touched. Planners: hypotheses or options rejected. Reviewers: axes covered, axes dropped.
